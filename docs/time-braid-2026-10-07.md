# 語る順と起きた順を一枚で比較する

全体図に「時間の編み図」を追加した。回想の多い作品では、読者順と時系列を切り替えるだけでは、同じ場面の位置を覚えておく必要があった。上下の二つの並びを同時に表示し、同じ場面を曲線で結ぶことで対応を見られるようにした。

「物語マップ → 全体図 → 時間の編み図」で開く。上は読者に語る順、下は作中で起きた順。場面を選ぶと対応する一本が強調され、下の感情の地図と右の詳細も同じ場面に移動する。人物を選んでいた場合はその人物を引き続き追える。数値は順位で、経過時間の長さではない。舞台裏は破線で区別する。

感情の地図の見せる順・時系列を切り替えても、編み図の二つの並びはそれぞれの役割を保つ。編み図は比較と移動のための表示で、並べ替えは感情の地図の場面名から行う。どちらかの順を変更すると編み図にも反映される。

24場面を超えると場面名を点へ圧縮し、全場面の対応線を残す。場面数に応じて背景線を薄くする。場面名の選択欄からも移動でき、各並びでは矢印キー・Home・Endで場面を辿れる。一つの並びにつきTabで止まる場面は一つに絞った。短い作品では場面名を直接表示する。

普段は折り畳んで、感情の地図の高さを確保する。開閉状態は開いている作品内の表示メモリに保持する。作品を閉じたりアプリを再起動したりすると初期表示に戻る。
