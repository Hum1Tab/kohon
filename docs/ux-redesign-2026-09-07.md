# KOHON UI / UX 改善

## デザイン方針

参照指定された hum1.dev のローカル実装（app/globals.css と app/page.tsx）から、暗いインク色と明るい紙色の対比、明朝系の見出し、丸みのあるカード、ピル型ナビゲーションを採用。アクセントは提供された KOHON ロゴのティール／ミントに合わせた。本文の配色・書体設定は維持し、操作領域だけを整理した。

## 分析と変更

| 問題 | 改善 |
| --- | --- |
| 起動時に毎回作品ファイルを探す | 最近の作品を永続保存し、ホームから続きを開ける |
| アイコンだけでは用途が分かりづらい | 左ナビを常時ラベル表示、本文検索と章の操作も明示 |
| レイアウト変更がメニューの奥にある | 執筆・推敲・比較を上部から直接切り替え |
| 執筆時も補助画面が場所を取る | 初期状態は本文中心。推敲時に編集レンズを表示 |
| パネルを閉じると右側に大きな空白が残る | 表示中の分割比率を正規化し、残りの幅を使い切る |
| 操作部品の密度と見た目が不統一 | 余白、角丸、境界線、設定画面、ダイアログを統一 |
| 押した感触・フォーカスが弱い | 短いホバー／押下応答とキーボードフォーカス表示。動きを減らす設定にも対応 |

ロゴからホームへ戻る際は保存キューの完了を待つ。最近の作品は登録済みの正規化パスのみ開き、任意パスへのアクセス許可には利用しない。

## 検証

- デスクトップ側 TypeScript 型チェック成功。
- デスクトップ側 Vitest：16ファイル、52テスト成功（ホーム、最近の作品、レイアウト等を含む）。
- Vite renderer / esbuild main / preload のビルド成功。
- git diff --check 成功（既存SVGの改行変換警告のみ）。
- 隔離プロファイルと専用サンプル原稿で、作品を開く、再起動後の最近の作品、本文入力と自動保存、本文検索「雨」の1件一致、推敲・比較への切り替え、保存してホームへ戻る動作を確認。
- 実画面でホームのライト／ダーク配色と、本文領域の空白解消を確認。

ユーザーの実原稿は変更していない。外部AIへの送信は行っていない。リポジトリ全体の旧テストには依存不足があるため、全体テスト成功とはしていない。インストーラーの再生成・配布は対象外。
