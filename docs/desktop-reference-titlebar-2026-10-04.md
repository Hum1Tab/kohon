# 通常起動時のタイトルバーと配布版

添付のVS Code画面に合わせ、上段にロゴ・メニュー・中央のコマンド検索・ウィンドウ操作、その直下に章タブを置く構成へ変更した。前回の単独エディターの一段統合を更新したもの。

- 上段36px、章タブ35px。通常の本文スクロール領域はウィンドウ上端から71pxで始まる。
- Windowsのタイトルバーと標準メニューバーの独立した行は表示しない。最小化・最大化・閉じるはOSのボタンをそのまま使う。
- ファイル・編集・設定・表示・ヘルプは、既存のネイティブメニューの見出しを上段に並べる。クリックすると対応する実際のサブメニューが開く。F10でメニューへ移動し、左右キーで見出しを切り替えられる。
- 作品名は中央の検索ボタンへ表示。作品名の変更はファイルメニューとコマンド検索へ移し、既存の機能を維持した。
- ライト・ダークの設定と、緑のロゴは維持。狭い画面では検索の幅とショートカット表示を調整する。

## 配布版

古い配布exeは変更せず、`apps/novel-editor/release/reference-ui/` に0.2.4のセットアップ版とポータブル版を生成した。公開・インストールは行っていない。

依存関係の収集でpnpmのnpm aliasが省略され、同梱のCodex実行環境が抜けていたため、build hookで対象OS・CPUのインストール済みパッケージを明示的に含める。実行ファイルは既存のasarUnpack規則で展開される。必要な対象パッケージがなければ配布ビルドを失敗させる。

## 確認

- TypeScript型チェック、Vitest32ファイル・109テスト、production build、git diff --checkが成功。
- 隔離プロファイルのElectron操作確認27項目が成功。1440×920と980×680、メニューの位置・F10・左右キー、タブ・検索・分割・集中モード・縦書きを確認。
- 新しいポータブルexeを通常のWindowsプロセスとして起動し、テスト作品を開いた。メニューとOSのボタンが同じ上段にあり、章タブが直下にあることを画面で確認。最大化後も表示が収まり、復元・閉じるのOS操作が利用できる。
- 配布asar内のHTML、rendererのJS/CSS/ロゴ、main、preloadの6ファイルが開発ビルドと一致。SHA-256を `SHA256SUMS-windows-x64.txt` に保存。
- 対象CPUのCodex実行ファイルがasar外に展開されていることを検査し、配布フォルダー内の実行ファイルで `--version` が成功（`codex-cli 0.152.0`）。

画面構成は開発ビルドのキャプチャ `.cache/desktop-frame-after/`、通常exeの確認には専用の `.cache/packaged-frame-profile/` を使用した。既存の利用者設定や作品への書き込みは行っていない。

メニューには [Electron Menu API](https://www.electronjs.org/docs/latest/api/menu) の既存サブメニューとpopupを使用する。
