# KOHON name preflight

Checked on 2026-09-03 immediately before the clean repository launch. This is a practical collision check, not a legal trademark opinion.

## Results

- `Hum1Tab/kohon` did not exist on GitHub and the authenticated account could create it.
- GitHub repository search returned Kohonen neural-network projects, but no writing editor or close product named KOHON.
- The npm registry had no exact `kohon` package and no `@kohon/desktop` package. The desktop workspace remains private and is not intended for npm publication.
- Web searches for `KOHON` with novel, editor, software, and Japanese trademark terms did not find a writing product with the exact name.
- [Koho](https://www.kohosales.com/) is an established Finnish project/ERP product. It is a different spelling, market, and visual identity, but should remain on the watch list if KOHON becomes a commercial service.
- RDAP returned an existing record for `kohon.com`; `kohon.app`, `kohon.dev`, and `kohon.jp` returned no record at check time. A missing RDAP record is only a reference and does not reserve a domain.

## Decision

No obvious same-market collision blocks the open-source `Hum1Tab/kohon` launch. Do not claim trademark registration or exclusive rights. Re-run an official trademark search and obtain professional advice before paid distribution, company formation, or a broader brand campaign.
